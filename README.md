# 📚 b-lang-more-examples

Example programs for the [b language](https://github.com/dimasbotyara/b-lang) — from first scripts to mini-projects.

| File | What it shows |
| --- | --- |
| `calculator_v2.b` | Calculator with the math module |
| `colors_showcase.b` | Colors & styles of output |
| `countdown.b` | Countdown timer |
| `fibonacci.b` | Fibonacci sequence |
| `fizzbuzz.b` | Classic FizzBuzz |
| `guess_game_advanced.b` | "Guess the number" game |
| `multiplication_table.b` | Multiplication table |
| `password_gen.b` | Password generator |
| `quiz.b` | Quiz game |
| `temperature.b` | Temperature converter |

## Run

```bash
# from the b-lang repo
python b.py examples/fibonacci.b
```

Copy any file into a folder with `b.py` (or wherever `b` is installed) and run it.
